# FR-001-008 ExecutorTimeline: Executor "48-60-6" Action Framework

## Description
The system shall present the executor action framework so the client/family knows what to do,
who to call, and in what order after a death: first 48 hours, first 60 days, first 6 months.

## Acceptance Criteria
1. Summary/report includes the 48-60-6 framework: first 48 hours (secure the house/mail, locate
   the original will, register the death), first 60 days (notify institutions, claim the CPP
   death benefit, gather documents), first 6 months (apply for probate, file the final CRA
   return, obtain the clearance certificate).
2. The framework references where key records are kept (captured in FR-001-003).
3. The framework is shown in both advisor and client views (FR-001-006).
